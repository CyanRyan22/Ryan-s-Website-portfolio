# My Portfolio Website

My basic and clean, responsive portfolio website
## 🔗 Project Links
* **Live Deployment URL:** https://cyanryan22.github.io/Ryan-s-Website-portfolio/
* **GitHub Repository:** https://github.com/CyanRyan22/Ryan-s-Website-portfolio.git

## 🛠️ Deployment Steps
1. Clone this repository using `git clone https://github.com/CyanRyan22/Ryan-s-Website-portfolio.git`.
2. Open `index.html` locally to preview the code.
3. The project is configured with GitHub Pages. 

## 🧠 UI/UX Reflection
I designed this website with a dark backround so that it would ease your eyes and blue text because it stands out for clear distinction and also my favorite color is blue.
